# Piyush Pandey — Engineering Portfolio

Personal portfolio website showcasing software projects in Artificial Intelligence, Machine Learning, Network Security, and Cloud Architecture (AWS).

![Portfolio Preview](public/favicon.svg)

## 🚀 Features

- **Interactive Engineering Terminal**: Live multi-tab code inspector featuring real Python IDS pipelines, AWS Terraform infrastructure, and system telemetry.
- **Categorized Projects & Architecture Drawers**: Detailed breakdown of project design, metric badges, and expandable implementation highlights.
- **Peer-Reviewed Publications Spotlight**: Scholarly showcases with one-click BibTeX citation copying for accepted journal papers.
- **Technical Skills Matrix**: Filterable skills catalog spanning AI/ML, Cloud & Infrastructure, Languages, and Data Science.
- **Work Experience & Credentials**: Structured timeline with internship impact metrics and certified credentials (Oracle, IBM, Python).
- **Direct Outreach & Interactive Toast**: One-click clipboard copy for email and phone numbers with live Indian Standard Time (IST) clock.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVG vectors
- **Styling**: Modern CSS3 (CSS Variables, Grid, Flexbox, Glassmorphism)
- **Linter**: Oxlint

## 💻 Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Lint codebase
npm run lint

# Build for production
npm run build
```
